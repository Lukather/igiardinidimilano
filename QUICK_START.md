# I Giardini di Milano · Quick Start

## Development Setup

```bash
# Install dependencies
npm install

# Run tests (86 tests, all passing)
npm test

# Start dev server
npm run dev
# Opens http://localhost:3000
```

## Add Photos (Complete Workflow)

```bash
# 1. Ingest photo (interactive)
npm run ingest /path/to/photo.jpg
# Follow prompts for GPS confirmation, category, description, etc.
# Output: src/photos/{id}.jpg + src/data/photos/{id}.json

# 2. Publish: build the data, then the site
npm run build
# Output: src/data/photos.json + dist/ (self-contained, deployable)

# 3. Check dev server
# The site automatically updates with new photos
```

## Key Features

### Landing Page (Hero Section)
- **Left**: Well-maintained space photo (green tag)
- **Right**: Degraded space photo (red tag)
- **Center**: Title, claim, statistics
- **Animation**: Scroll hint that bounces

### Map Section
- Leaflet with CARTO tiles
- Green/red circle markers with white rings
- Click for photo details (thumbnail, date, coords)
- **Filters**: Toggle "Curato" / "In degrado" categories

### Accessibility
- ✅ WCAG AA compliant
- ✅ Colorblind-friendly markers
- ✅ Reduced motion support
- ✅ Mobile responsive
- ✅ Italian language

## Photo Requirements

| Field | Rules | Format |
|-------|-------|--------|
| **Location** | Must be in Milan (45.35-45.55, 8.95-9.30) | GPS coordinates |
| **Category** | Curato OR In degrado | Enum (objective checklist) |
| **Date** | When photo was taken | YYYY-MM-DD |
| **Description** | What you see in the photo | 10-500 characters |
| **Space** | Name of the green space | 1-100 characters |
| **Image** | Original photo with GPS EXIF | JPG/PNG, any size |

## Common Commands

```bash
# Development
npm run dev                # Start dev server
npm run test              # Run all tests
npm test src/main.test.ts # Test landing page only

# Data pipeline
npm run ingest PHOTO      # Add photo (interactive)

npm run build:site        # Build dist/ from existing data
npm run build             # Both, in order (the publication command)

npm run preview           # Preview dist/ locally
```

## Data Model

```typescript
// Photo record
{
  id: "2024-01-15-parco-sempione-01",      // Auto-generated
  category: "curato",                       // or "in degrado"
  coordinates: {
    latitude: 45.4642,                      // Within Milan bounds
    longitude: 9.1900
  },
  date: "2024-01-15",
  description: "Parco ben curato, erba tagliata",
  space: "Parco Sempione",
  imageFile: "2024-01-15-parco-sempione-01.jpg"
}

// Site data (generated by build)
{
  photos: [...],                            // Array of photos above
  stats: {
    totalPhotos: 42,
    curatedSpaces: 12,
    degradedSpaces: 9
  },
  lastUpdated: "2024-01-15T14:30:00Z"
}
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "photos.json not found" | Run `npm run build` |
| Map shows no markers | Photos need valid GPS coords in Milan bounds |
| Ingest fails to read EXIF | Photo must have GPS embedded; use `--skip-gps` flag |
| Tests fail | Run `npm install` and ensure Node 16+ |
| Dev server won't start | Kill any process on port 3000: `lsof -ti:3000 \| xargs kill -9` |

## Deployment

```bash
# 1. Build for production
npm run build

# 2. Deploy dist/ to hosting
# GitHub Pages: push dist/ to gh-pages branch
# Netlify: connect repo, set build cmd to "npm run build"
# Vercel: same as Netlify

# 3. Photos are updated via git
git add src/photos/ src/data/photos.json
git commit -m "Add 3 new photos"
git push
```
